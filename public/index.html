POC นี้ยืนยันการเชื่อมต่อ extension และ lifecycle ของแท็บที่เปิดจริง แต่ไม่อ้างว่ายืนยันตัวตนหรือ entitlement ของบัญชี Gemini

ติดตั้ง extension ครั้งแรกใน Chrome หรือ Edge

หากต้องแยกบัญชีแบบคง session ให้สร้าง browser profile เฉพาะก่อน แล้วติดตั้ง extension และลงชื่อเข้าใช้บัญชีที่อนุมัติใน profile นั้นเพียงครั้งเดียว

  1. ดาวน์โหลด extension v0.2.0 และแตกไฟล์
  2. Chrome เปิด chrome://extensions หรือ Edge เปิด edge://extensions
  3. เปิด Developer mode
  4. เลือก Load unpacked แล้วเลือกโฟลเดอร์ที่แตกไฟล์ไว้
  5. กลับมาหน้านี้และกด “ตรวจ extension อีกครั้ง”
