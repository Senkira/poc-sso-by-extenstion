POC นี้ยืนยันการเชื่อมต่อ extension และ lifecycle ของแท็บที่เปิดจริง แต่ไม่อ้างว่ายืนยันตัวตนหรือ entitlement ของบัญชี Gemini

ติดตั้ง extension ครั้งแรก
  1. ดาวน์โหลด extension v0.1.0 และแตกไฟล์
  2. เปิด edge://extensions และเปิด Developer mode
  3. เลือก Load unpacked แล้วเลือกโฟลเดอร์ที่แตกไฟล์ไว้
  4. กลับมาหน้านี้และกด “ตรวจ extension อีกครั้ง”
